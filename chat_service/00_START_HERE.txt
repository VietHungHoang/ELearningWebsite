📊 ARCHITECTURE:

REST API (Lịch sử):
├─ GET /api/v1/chat/conversations/{userId}

WebSocket (Real-time):
├─ Connect: ws://localhost:8084/ws/chat
├─ Subscribe: /topic/conversations/{conversationId}
├─ Send to: /app/chat/conversations/{conversationId}/send
└─ Typing: /topic/conversations/{conversationId}/typing
