# E-Learning Platform

A modern e-learning platform built with React, TypeScript, and Tailwind CSS.

## Project Structure

```
elearning-react/
├── frontend/          # React frontend application
│   ├── src/          # Source code
│   ├── public/       # Public assets
│   ├── package.json  # Frontend dependencies
│   └── ...
├── backend/          # Backend API (to be added)
└── package.json      # Root package.json for workspace management
```

## Getting Started

### Prerequisites

- Node.js (>= 18.0.0)
- npm (>= 8.0.0)

### Installation

1. Clone the repository:
```bash
git clone <repository-url>
cd elearning-react
```

2. Install dependencies:
```bash
npm install
```

3. Start the development server:
```bash
npm run dev
```

## Available Scripts

- `npm run dev` - Start the frontend development server
- `npm run build` - Build the frontend for production
- `npm run preview` - Preview the production build
- `npm run lint` - Run ESLint on the frontend code
- `npm run install:frontend` - Install frontend dependencies

## Frontend

The frontend is a React application built with:
- React 18
- TypeScript
- Tailwind CSS
- Vite
- React Router
- Zustand (state management)

## Backend

The backend will be added in the `backend/` folder for API development.
