1. ảnh AddToCard
có nút **add to cart**
=> ấn xong thì nút này sẽ chuyển thành "go to cart"
2. ảnh GoToCard
=> có 2 cách để vào **Cart**:
- ấn vào **go to cart**
- ấn vào biểu tượng *giỏ hàng*
3. ảnh Cart
Gồm 3 chức năng chính:
- **remove** sản phẩm khỏi giỏ hàng
- **apply coupon**: học viên code giảng viên cung cấp vào đây
- **checkout**: chuyển sang thanh toán 
4. các trường thông tin trong **cart**

- **tên** course
- **tên** tutor
- **tổng quan số giờ học, số bài học**

- **đánh giá**
